# Jozi Quest

A transport-aware Johannesburg orientation game for newcomers.

## Included modes
- Walking
- Driving
- Minibus taxi
- Cycling

## Challenge categories
- Mixed city
- Taxi ranks
- Major roads
- Landmarks
- Garages / fuel stations

## Run locally
Serve this folder with any static web server, for example:

```bash
python -m http.server 8000
```

Then open `http://localhost:8000`.

## Deploy
The app is static and includes a `vercel.json` file, so it can be deployed directly to Vercel with no build command.
